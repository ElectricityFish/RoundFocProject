# RoundFoc 固件工程

## 打开与构建

用 IAR Embedded Workbench for Arm 打开 `iar/RoundFoc.eww`。在 Project → Batch Build 中选择 `Debug` 构建两个核。也可在本目录执行以下 PowerShell 命令。

```powershell
& 'D:/IAR/common/bin/IarBuild.exe' 'iar/boot_cm0plus.ewp' -build Debug
& 'D:/IAR/common/bin/IarBuild.exe' 'iar/round_foc_cm4.ewp' -build Debug
```

两个核分别生成 `build/Debug/cm0plus/Exe/boot_cm0plus.hex` 和 `build/Debug/cm4/Exe/round_foc_cm4.hex`。同目录的 `.out` 带调试符号。复位启动需要两个镜像分别位于各自的链接地址。

### 从 IAR 下载双核固件

1. 连接逐飞 CMSIS-DAP 下载器并给目标板供电，在 IAR 打开 `iar/RoundFoc.eww`。
2. 首次构建或修改源码后，按 **F8**，选择 **Debug** 并执行 **Make**，生成两个核的最新镜像。
3. 将 **boot_cm0plus – Debug** 设为活动工程，选择 **Project → Download → Download active application**。IAR 通过 SWD 写入 CM0+ 启动程序和 CM4 电机程序，并执行下载校验。调试时可在 **View → Messages → Debug Log** 查看目标识别信息和下载字节数。

双核下载选项保存在 `iar/boot_cm0plus.ewd`。附加的 CM4 镜像采用工程相对路径，地址偏移为 0。下载范围为两个程序的 Code Flash，校准记录所在的 Work Flash 不参与常规下载。

## 上板运行六步换相

适配圆形自制板、板载 AS5047P 和龙邱 L4225-6S420-A（12 槽、14 极、7 极对）。台式电源设为 16.8 V，母线限流 3.2 A。本版固件无相电流采样或软件过流保护。复位、校准结束和故障停机时，EG2134 的六路输入均为低电平。

1. 用 DAP 下载本次构建的 CM0+ 和 CM4 两个镜像。CM0+ 配置系统时钟并响应 Flash 系统调用，CM4 执行电机控制。板上 Y1 是 16 MHz 主晶振，32 kHz 晶振位未接入。
2. 打开下载接口引出的串口。VOFA+ 选择 **FireWater、115200、8N1**，命令用 ASCII 文本发送，末尾加回车或换行。上电先手转一圈，观察机械角在 0～359.9° 间连续变化。角度通过诊断且没有已保存的校准值时，状态为 0。
3. 发 `cal`。保持转轴能自由跟随。固件从低占空比开始对齐，再沿六个电角度扇区各走一个电周并折返。约 1.2 s 检查第一步位移，完整往返约 5.6 s。方向、极对数对应的位移和回零一致性均通过才会保存。状态 1 表示已保存且处于待机。
4. 例如发 `run 3`，给定 **3% 占空比**。支持一位小数，如 `run 4.5`，也可带百分号。运行中可用同一命令调整给定。电机持续转动，发 `stop` 关断六路输入，`run 0` 同样停机。转速供观察。
5. 下次上电将加载最近的有效校准值，等待 `run`。更换电机、调换相线或调整磁铁安装位置后，先 `stop` 再 `cal`。校准过程中发 `stop` 可中止运动并保留之前的记录。排除故障后发 `stop` 回到待机或待校准。

### VOFA+ 四个通道

每 20 ms 输出一行 `机械角,机械转速,通电矢量编号,状态码`。机械角单位为度，随 AS5047P 原始读数增大。转速单位为 rpm，按 20 ms 位移估算。首次校准前转速符号随编码器，校准后按换相表正向运动为正。矢量编号 1～6，关桥时为 0。

| 状态码 | 含义 |
| --- | --- |
| 0 / 1 | 待首次校准 / 已校准待机 |
| 2 / 3 | 正在校准 / 正在运行 |
| -1 | 编码器 SPI 超时、帧校验、磁场诊断或运动中角度连续性异常 |
| -2 | 校准时转子未稳定、步进位移或往返电角度零位超差 |
| -3 | 运行时连续 500 ms 未累积到约 2.8° 正向机械位移 |
| -4 | Flash 系统调用、读取或保存校验失败 |
| -5 | 通电期间位置采样间隔超过两个控制周期 |
| -6 | 命令格式、给定范围或当前状态不允许，提示一帧 |
| -7 | 板级外设或控制时基初始化失败 |

PWM、换相间隔、自举时间、校准占空比和试车上限是待实物核对的实验初值。板级时序在 `app/board.c`，电机参数及校准流程在 `app/motor.h` 和 `app/motor.c`。门极波形和自举电压仍待实测。编码器和驱动接口定义见 [AS5047P 数据手册](https://datasheet.lcsc.com/datasheet/pdf/f756e23b78f013a17a23aa4fb991cabd.pdf?productCode=C55112284) 和 [EG2134 产品资料](https://egmicro.com/products/detail/?name=EG2134)。

2026-11-28 移近磁铁后，实板读角恢复。原设定为 3%、对齐 400 ms、每步 150 ms。第一步的两个稳定位置为 356.90° 和 356.99°，实际位移约 0.09°，触发状态 −2。

同一块板改用 5%、对齐 800 ms、每步 400 ms 后，先读到的一轮前三步机械位移依次为 +12.66°、+8.31°、+13.32°（第一步跨过 360°）。第三步取样 81 次，末 20 ms 的角度峰峰值约 0.13°。第三步位移超过 12.85° 上限，固件在约 2.0 s 关桥。

随后用户触发的一轮完成了正向六步和反向六步，12 个单步位移全部通过。去程总位移为 44.85°，回程为 51.39°，每程允许 48.21°～54.62°。起止均为 U+ V−，但两次稳定位置分别为 56.51° 和 49.97°，回零误差 6.55° 超过 2.13° 上限。其余五个矢量往返时对应位置相差至多 0.09°。最终 I2 为 0、I3 为 −2，本次校准未写入 Flash。

### 5% 和 7% 校准占空比实板对照（2026-11-28）

在相同的约 117.2° 初始机械角，从 COM13 发送 `cal`，用 CMSIS-DAP 在关桥后读取末段平均位置。两次 5% 的曲线均在首次对齐约 0.3 s 后稳定，最后 200 ms 的角度峰峰值分别为 0.1°、0.2°。第一轮前两个通电位置为 101.36°、116.24°，相差 14.88°，超过单步 12.85° 上限。第二轮稳态位置同样约为 101.3°、116.2°。编码器传输、帧校验和磁场诊断的错误计数均为零。

仅将校准占空比提高到 7%，比较寄存器由 200/4000 变为 280/4000。预期是转子稳定位置更接近各通电矢量的理论间距。以下为三轮完整校准的实测机械角，每一步与电角度零位均通过原有判据。相邻极对的起点通过一次中途 `stop` 的校准去程取得。

| 起始机械角 | 第一步位移 | 去程总位移 | 回程总位移 | 回零误差 | 保存的电角度零位（计数/16384） |
| --- | --- | --- | --- | --- | --- |
| 117.2° | 9.47° | 51.31° | 51.17° | 0.132° | 550 |
| 100.3° | 9.40° | 51.22° | 51.20° | 0.022° | 550 |
| 155.7°（相邻极对） | 8.35° | 51.83° | 51.88° | 0.044° | 408 |

7% 改善了这块板上的静态定位。相电流和门极波形仍待实测。XRES 硬件复位后，步进记录已清零，两份 Work Flash 记录的 CRC 均通过，从序号 3 恢复零位 408、方向 +1。COM13 持续上报 I2=0、I3=1。IAR 命令行的 System 复位曾停在 CM0+ 启动阶段，本次用下载器脉冲 XRES 验证复位加载。

原始数据位于工作区 `遥测数据/20261128_alignment_*`。CSV 的 `host_ms` 是主机收帧时间，四个串口通道每 20 ms 一帧，原始角度随编码器方向增大。SWD 表中的 p0～p12 是固件 4 kHz 读取后取各通电段末 20 ms 的平均机械位置，单位为每圈 16384 计数。5% 和 7% 两个 CM4 Debug 镜像的有效程序字节 SHA-256 前缀分别为 `e6e103824f21` 和 `a01d91219057`。在工作区根目录可用以下命令重绘首轮对照，图中稳态位移使用各段最后五个串口样本的中位数。

### 编码器故障的实板记录（2026-11-28）

更换同型号 U7 后，停机时 COM13 持续上报 `0.0,0,0,-1`。SWD 读到 ECO 就绪、PLL 锁定，CM4 为 160 MHz，外设时钟为 80 MHz。SCB3 分频为 5、过采样为 8，对应 2 MHz 的 SCLK，配置为模式 1、16 位、MSB 先行。SysTick 重装值为 39999，优先级为 7，4 kHz 计数持续递增。SPI 由主循环轮询 FIFO，SCB3 的中断掩码均为 0。

在 CM4 的 IAR Watch 中查看 `encoder_diag`。`transfer_errors` 统计发送失败或超时，`frame_errors` 统计返回帧的奇偶校验或 EF 错误，`diagnostic_errors` 统计磁场和芯片内部诊断未通过的采样。`diaagc`、`anglecom` 保留原始 16 位响应。发生帧错误时，`errfl_received` 表示已收到 ERRFL 读命令的下一帧响应，可在 `errfl` 查看原始字。

本次读到 222365 次磁场诊断未通过，传输错误和帧错误均为 0。`DIAAGC = 0x09FF` 表示内部校正完成（LF=1）、磁场偏弱（MAGL=1）、自动增益达到 255。芯片返回的角度约为 117.8°，固件保留上一次通过诊断的角度用于遥测，首次通过前 I0 为 0。排查磁铁充磁方向和有效气隙时，观察 MAGL 是否清零，并检查缓慢手转一圈时 I0 能否连续变化，再进行首次校准。[AS5047P 磁场规格与 DIAAGC 位定义](https://www.mouser.com/datasheet/2/588/AS5047P_DS000324_3_00-1843440.pdf)

原超时恢复调用 SDL 的 `Cy_SCB_SPI_Disable()`，会清空 SCB3 的 `CTRL`，丢失 SPI 模式、FIFO 宽度和过采样设置。固件现仅清除使能位，关片选、清 FIFO 后重新使能。主机模拟注入一次超时后，下一次能正常读角。实板采集期间未触发超时。

### 校准记录

使用单 Bank 模式下的片内 Work Flash。CM4 以 IAR `__no_init` 对象保留 `0x14018000` 和 `0x14018080` 两个独立的 128 字节小扇区。普通启动仅读取。记录含格式和电机配置标识、序号、编码器方向、电角度零位、CRC32 和提交标记。每次成功重校先关桥，将备用扇区擦除并写入，读回校验后最后写提交标记。复位时校验两份记录并取最近有效的一份。下载选项中的整片擦除若包含 Work Flash，将需要重新校准。

读取先通过 SROM 检查空白，再通过 M-DMA 通道 0 读取已编程的记录。掉电可能留下不可纠正的 ECC 错误，DMA 能把该记录作为无效数据处理并继续检查另一扇区。[英飞凌 Flash 访问说明](https://documentation.infineon.com/traveo/docs/grn1680597195267) · [CYT2BL Rev. A 勘误 137](https://www.infineon.com/assets/row/public/documents/10/52/infineon-cyt2bl-a-errata-rev2.3.pdf-erratasheet-en.pdf)

## 器件和标准库

编译暂按 `CYT2BL3CAE`、`tviibe4m`、`CY_MCU_rev_a` 配置。板图仅标注 CYT2BL3，首次下载前请核对实物完整料号和封装。两个核共用 SDL 自带的 IAR 链接脚本，CM0+ 和 CM4 的向量表分别位于 `0x10000000` 和 `0x10080000`。

`vendor/sdl/8.7.0` 收录本工程使用的 Infineon TRAVEO T2G Sample Driver Library 子集。来源为本机归档的官方包，`provenance.json` 保存包来源和各文件 SHA-256，`License.txt` 随附。升级时同步核对双核器件宏、启动代码和链接布局。[英飞凌 SDL 说明](https://documentation.infineon.com/traveo/docs/lwy1680596932876)
